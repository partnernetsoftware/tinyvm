## 判据 ③（主判据，加一个**方法**的边际）：**先读成陡，做了逐方法门控后是 0**

**第一次读数（整集合一刀切的门）**：实现第二个方法 `indexOf` 之后，重测**同一个只
调用 `trim()` 的程序**：

| 程序 | 集合里 1 个方法 | 集合里 2 个方法（一刀切） | 变化 |
|---|---|---|---|
| `return "  a  ".trim();` | Δ **428** | Δ **735** | **+307** |

一个只写 `trim()` 的程序，为它永远不会调用的 `indexOf` 多付 307 字节。
按 §4 判决树第 1 条，这是「线性且陡」，本该判 C 负。

**但没有落判决，因为一刀切是本实现的选择、不是变体 C 的定义。**
做了**逐方法门控**（`method::Plan`：调用点要哪个就发哪个，helper 按依赖拉入）后重测：

| 程序 | 逐方法门控后的 Δ |
|---|---|
| 只用 `trim` | **428**（回到只有一个方法时的数） |
| 只用 `indexOf` | **364** |
| 两个都用 | **784** |

**加第五个方法，对不调用它的程序边际是 0。** 判据 ③ 因此**不判 C 负**。
（428 + 364 = 792，实测 784，8 字节的差在 LEB128 宽度与字面量上；
两个方法之间**没有**共享成本，符合「各付各的」。）

**这次修改本身的代价要算在 C 头上**：`method::Plan` 是 **27 行**（非空非注释），
而且它存在的理由是函数索引由**位置**决定——抽掉一个成员后面全挪，
正是 `plan/design-string-length-milestone.md` §3 里 `Rt::Len` 那个问题的第二次相遇。
**A、B 不需要这 27 行**：它们的方法是函数值，只有被引用的那个才需要存在。

**方法论上的一条**：第一次读数如果当场落判，就会用一个**可修的实现细节**
判掉一个变体。§4 判决树该在「这个数是变体的性质还是这次实现的性质」问清楚之后才走。
这条已写进本文件，也是这条轨迄今最值钱的一次教训。

## 判据 ⑥ 泄漏清单（变体 C，六条）

1. **运行期接收者测试省不掉。** 源码写 `x.trim()`，`x` 是 String 还是带 `trim`
   属性的对象要到运行时才知道，而
   `method_conformance::a_plain_object_property_named_like_a_method_is_untouched`
   就是「第二种必须照常工作」的断言。所以 C **省掉的是函数值，不是分派**——
   分支只是从被调用者的值里搬到了每一个调用点上。这就是那 43–53 字节。
2. **接收者只能求值一次**，所以非快路那条**不能**退回去调现成的 `indirect_call`
   ——那会重新降级 callee，`f().trim()` 会把 `f` 调两次。于是必须有暂存对 +
   两个 `If` 的形状。
3. **IR 没有 `Else`，`BlockType` 只有 `Empty`**，所以「产生一个值的分支」必须
   经由局部变量绕一圈。IR 的性质，但**付钱的是变体**。
4. **`map` 没有 prefab，只能在调用点内联。** 全仓**没有任何 runtime prefab 能
   `call_indirect`**（唯一一处在 `emit.rs`），而 `map` 必须回调进函数值。
   C 靠「在调用点内联」绕开了，代价是 ③b 三倍。**A、B 绕不开**：它们的方法**是**
   函数值，方法体就是函数，那个函数需要的正是 C 避开的那个能力。
   **这是本轨迄今最结构性的一条发现。**
5. **跨门依赖。** `__m_push` 要靠 `__arr_push`，那在**数组**集合、**数组**门后面。
   于是一个 `push` 调用点必须伸手把另一个不相干的门打开。A、B 的方法体一样依赖它，
   但不需要**编译器**知道——它们经由值到达，而不是经由这个模块要算出来的索引。
6. **接收者测试是逐方法的。** `trim` 要 String、`push` 要 Array，所以调用点上的
   类型测试不是一个共享检查，而是每个方法一份。小，但扛着它的是调用点。

另记两条**不是**泄漏、但影响读数的事：

- `objtrim` 花 429 字节却一次也到不了 prefab——**门不精确**，也不可能精确（同泄漏 1）。
- `ws_width` 只认 ECMA-262 12.2/12.3 里**具名的十个**，不认 `Zs` 其余
  （U+1680、U+2000..200A、U+202F、U+205F、U+3000）。**已知缺口**，三变体同价，
  不影响比较；方法体若被扶正必须先补。
